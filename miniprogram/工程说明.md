# 小程序工程说明与改动速查

代码里每个文件顶部都写了详细注释，说明它是干什么的、改哪里会有什么效果。
这份文档补两块代码注释放不下的内容：

1. **`.json` 配置文件的说明** —— JSON 格式不允许写注释，加了会编译报错，所以只能写在这里
2. **跨文件的改动索引** —— 很多改动要同时动两三个文件，这里列清楚配套关系

## 二、`app.json` 逐项说明

这是全局配置，改错会导致编译失败或页面白屏。

```json
{
  "pages": [ ... ],
  "window": { ... },
  "tabBar": { ... },
  "sitemapLocation": "sitemap.json",
  "style": "v2",
  "lazyCodeLoading": "requiredComponents"
}
```

### `pages` 数组

所有页面必须在这里登记，路径不带开头的斜杠、不带文件后缀。

**第一项是启动页**，也就是用户打开小程序看到的第一个页面。想让小程序默认打开超级杯，
把 `pages/super-cup/index` 挪到第一位即可。

新增页面时必须做两件事，漏了会出问题：

1. 加到这个数组里（漏了会报 `page not found`）
2. 加到 `utils/navigate.ts` 的白名单里（漏了点击入口只会弹提示，不跳转）

### `window` 段

```json
"navigationStyle": "custom"
```
**这是最关键的一项。** `custom` 表示不用微信自带的顶部标题栏，改成自己画。
我们选它是因为设计稿要求头部是通栏渐变，原生标题栏做不到。

代价是要自己避开手机状态栏：

- **三个 Tab 页**（首页 / 超级杯 / 我的）自己画顶栏，写 `padding-top:{{statusBarHeight}}px`
- **二级页**打开 `page-nav` 的 `occupy="{{true}}"`，组件内部会量，页面不必再抄一份

如果改回 `default`，会出现微信自带的白色标题栏，同时页面头部会多出一段
空白（因为 padding 还在），需要把各页那行 padding / occupy 一起去掉。

```json
"backgroundColor": "#F0FCF7"
```
页面下拉时露出的底色，以及页面内容不足一屏时下方的颜色。
这是冷启动默认（薄荷）。用户在「我的」换了背景之后，运行时会再调
`wx.setBackgroundColor`，所以不要指望只改这一项就能换主题。

```json
"navigationBarBackgroundColor": "#B8EDDC",
"navigationBarTitleText": "LTJIMMY赛事",
"navigationBarTextStyle": "black"
```
因为用了自定义导航栏，这三项在页面上看不到效果。但它们仍然有用：
小程序在**加载中的那一瞬间**、以及分享卡片上会用到，所以别删。

### `tabBar` 段

```json
"custom": true
```
表示用我们自己的 `custom-tab-bar/` 组件替代原生底栏。原因是设计稿的底栏有
3D 图标和圆形光晕，原生底栏只支持"一张图 + 一行字"。
选中字色和光晕跟 `THEME_CHROME` 的 accent 走，组件已挂 `themeBehavior`。

**即使用了自定义底栏，下面的 `list` 也必须保留**，微信靠它知道哪三个页面是 Tab 页
（决定了 `wx.switchTab` 能跳到哪里）。`list` 里的 `text` 在自定义底栏下不显示，
真正显示的文字在 `custom-tab-bar/index.ts` 的 `TABS` 数组里。

**两处的顺序必须一致**，否则点击会跳错页面。

```json
"color": "#6B7566",
"selectedColor": "#59850A"
```
同理，自定义底栏下这两个颜色不生效，实际颜色在 `custom-tab-bar/index.wxss` 里。

### 其他

```json
"style": "v2"
```
启用新版组件样式。别关，关了按钮输入框的默认样式会变回很旧的样子。

```json
"lazyCodeLoading": "requiredComponents"
```
按需加载组件代码，能让小程序启动更快。保持开启。

## 三、`project.config.json` 说明

仓库根目录和 `miniprogram/` 里各有一份。**请用微信开发者工具打开仓库根目录**，
根目录那份才有 `cloudfunctionRoot`，云函数会出现在工具左侧。

```json
"miniprogramRoot": "miniprogram/",
"cloudfunctionRoot": "cloudfunctions/"
```

表示小程序代码在 `miniprogram/`，云函数在 `cloudfunctions/`。

```json
"appid": "REPLACE_WITH_YOUR_APPID"
```
**这里必须换成你自己的 AppID**，否则无法预览和上传。在微信公众平台
「开发 - 开发设置」里能看到。

```json
"setting": {
  "useCompilerPlugins": ["typescript"]
}
```
让开发者工具自动编译 TypeScript。**去掉这项，所有 `.ts` 文件都不会生效，
页面会变成完全没有交互的静态页。**

```json
"minified": true
```
上传时压缩代码，能显著减小包体积。保持开启。

另外会有一个 `project.private.config.json`，那是开发者工具自动生成的个人配置
（含本机路径），已经加进 `.gitignore` 不上传。

云函数写好后，在开发者工具里对 `cloudfunctions` 下每个文件夹右键「上传并部署：云端安装依赖」。
控制台「云函数」里才能看到。没上传时，登录和灌赛事会失败，控制台会有提示。

## 四、页面的 `.json` 说明

每个页面目录下的 `index.json` 只有两项：

```json
{
  "navigationStyle": "custom",
  "usingComponents": {
    "event-card": "../../components/event-card/index"
  }
}
```

`usingComponents` 是这个页面用到的组件清单。**用了组件却没在这里注册，
页面上那个组件的位置会完全空白，而且控制台不一定报错**，是个很难找的问题。
反过来注册了没用也没关系，只是多余。

路径 `../../` 表示从页面目录往上两级回到 `miniprogram/` 根目录，末尾不写文件后缀。

`image-cropper` 是通用裁剪框：页面传入图片路径和 `aspect-ratio`（宽÷高），用户拖框 / 拉四角预览，确认后回 `bind:confirm` 的 `path`。json 里不能写注释，用法写在组件 `index.ts` 头部。封面裁切按「我的」头图窗口实时量比例，不要写死 16:9。

## 四（附）、全站主题怎么接

换颜色只动 `utils/theme.ts` 的 `THEME_CHROME`。不要在页面里写死青绿。

**新页面 / 新组件只做两步：**

1. `behaviors: [themeBehavior]`（从 `behaviors/theme.ts` 引入）
2. 根节点写 `style="{{themeVars}}"`；按钮、筛选、光晕用 `{{accent}}` 或 `var(--accent)`

挂上就会自动登记、自动刷色。不要再手写 `register` / `apply`。

**二级页头部：** 一律 `<page-nav title="..." occupy="{{true}}" />`。
`occupy` 会垫出和吸顶栏一样高的空白，下面内容不会被挡住。
不要再给新页套 `.header` + `.header__wave`（那套只留给未引用的 `hero-carousel`）。

三个 Tab 页（首页 / 超级杯 / 我的）自己画顶栏，用 `headerMetrics()` 量状态栏。
店铺页的赛事 / 球员榜 Tab 也自己量；切到相册 Tab 改用 `page-nav occupy`。

`styles/theme.wxss` 是 `.theme-*` 的备份，和 `THEME_CHROME` 必须一致。
真正换色靠内联 `themeVars`，因为微信里 class 上的 CSS 变量经常压不过 `page {}`。

### 容易踩的坑

1. **改了筛选项名字但忘了改数据键名** —— 切过去是空列表。两处必须一字不差。
2. **加了宫格入口但没加大高度** —— 赛事详情等仍按固定高度裁切的宫格，新增行会看不见。超级杯 V5 已改成 Cover Flow，不再读 `--grid-height`。
3. **新二级页忘了开 occupy** —— 吸顶栏是 `position: fixed`，不开 occupy 下面第一行会被挡住。
4. **改了元素高度但没改对应的圆角** —— 药丸形按钮变成圆角矩形。规律是圆角 = 高度的一半。
5. **用了组件但没在页面 json 里注册** —— 那块位置完全空白，且不一定报错。
6. **新增页面只加了 `app.json` 没加 `navigate.ts` 白名单** —— 入口点击只弹提示。
7. **页面里新调了 `wx.xxx`，但没写进 `typings/miniprogram-api-typings/index.d.ts`** —— 问题面板会报「属性不存在于类型 Wx」。开发者工具把类型错误当成编译失败，模拟器整页白屏（首页也白，不一定是首页本身坏了）。
8. **想让返回/标题吸顶却把 sticky 写在 `.header` 里** —— sticky 出不了父级，头部滚走标题栏也没了。用 `components/page-nav`（fixed + occupy）。
9. **WXSS 类名不要写中文** —— `.sched__st--已结束` 这类选择器会编译失败（`unexpected` 乱码），页面样式整份作废。画面上仍显示中文，类名用英文（如 `--done`），由 `statusTone` 去拼。
10. **只改 `tokens.wxss` 的 `--brand-lime` 指望全站换色** —— 现页选中色走 `--accent`，要改 `THEME_CHROME`。
11. **裁剪器和战力图都是 canvas 原生层** —— 普通遮罩压不住。打开 `image-cropper` 时要卸掉页面上其它 canvas，并 `setTabBarHidden` 藏自定义底栏。
12. **想弹出微信选手机号，却用了普通 view / wx.login** —— `wx.login` 没有界面。必须用 `<button open-type="getPhoneNumber">`，用户点这颗按钮才会出系统选号层。

## 六、关于字号

卡片标题 24rpx（约 12pt），而 iOS 常规正文是 14–17pt。

目前严格按设计稿实现，没有擅自放大。如果真机上确认偏小，要调的主要是这几处：
